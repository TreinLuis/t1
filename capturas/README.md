# Capturas a gerar na rede do laboratório

Esta pasta não contém evidências fabricadas. Salve aqui:

- `c1.pcapng`: 10 pedidos sequenciais, uma conexão por pedido.
- `c2.pcapng`: 10 pedidos sequenciais, uma conexão persistente.
- `transacao.pcapng`: GET de outra máquina, com abertura, resposta e encerramento.
- `concorrencia.pcapng` ou evidência de log: clientes de dois IPs atendidos simultaneamente.

O GET completo pode ser um stream de C1; nesse caso, cite arquivo e stream no relatório.
Guarde IPs/interface, comandos, RTT, horário e os números das tramas anotadas.
Use o roteiro do README principal. Não use loopback para as medições obrigatórias.
